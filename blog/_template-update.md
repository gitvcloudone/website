Write it the way you'd explain it to a customer. Don't just list features: explain each one the first time it comes up. What is it, how does it work, and what does it change for a design, an operation or a bill? Give a number or an example where it helps. By the end, a reader should know what changed, why it matters and whether it's for them. No need to label those parts.

Lists are fine when there are several items:

- First thing
- Second thing
