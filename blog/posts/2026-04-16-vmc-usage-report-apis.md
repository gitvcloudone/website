## What
Two new APIs: a Miscellaneous Usage Report for extra charges like Elastic IPs, Transit Gateway and data transfer, and a Microsoft SPLA Usage Report. They sit alongside the Host Usage Report API from last November.

## Why it matters
You get daily usage data you can filter, so VMC spend can go into the same cost and BI tools as the rest of your cloud bill instead of waiting on invoices.

## Who it's for
FinOps and cost teams tracking VMC spend.
