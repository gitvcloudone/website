With SDDC 1.26v2, VMware Cloud on AWS supports i7i.metal-24xl for new and existing SDDCs in select Regions. It comes with host-to-host encryption, vSAN data-at-rest encryption and Intel TME memory encryption.

A few things to know before you plan on it. Existing SDDCs need to be on 1.26v2 first. vSAN ESA is only for new SDDCs or new secondary clusters. Hyper-threading is on by default, giving 96 logical cores per host. And stretched clusters on i7i use vSAN OSA.

If you're on i3, i3en or i4i and thinking about a host refresh, this is the newer host to look at. It's also a good option for new SDDCs.
