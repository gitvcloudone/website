The host limit for an Amazon EVS environment went from 16 to 32. You get there by asking for a service quota increase, and it's available in every EVS Region.

An EVS environment is one VCF instance: one management domain with vCenter, NSX, SDDC Manager and VCF Operations, and the hosts and clusters it manages. The 32 hosts can be one large cluster or several smaller ones across VCF domains.

**Why it matters.** Every environment carries its own management stack. That's management VMs eating capacity, appliances to patch and upgrade, and another set of DNS records, BGP peers and certificates to look after. If you needed more than 16 hosts, you had to run two environments and pay that overhead twice. Now many estates fit in one.

**Watch the quota.** It's a quota, so it isn't automatic, and it isn't the only one that applies. Bare-metal hosts count against your EC2 On-Demand vCPU quota too, so check both before a large build. If you need more than 32 hosts in one VCF domain, you still need to design around the limit.
