SDDC 1.26v3 is a maintenance release for VMware Cloud on AWS, with quality and stability fixes. It's also the first release to deal with an expiring Microsoft Secure Boot certificate.

Secure Boot checks that each piece of boot code is signed by a trusted key before it runs. Many of the keys VMs trust today come from Microsoft certificates issued in 2011, and those certificates expire during 2026. VMs need the newer 2023 certificates in their firmware to keep trusting updated boot components. 1.26v3 starts the platform work for that.

If you run Windows VMs, or Linux VMs that boot through Microsoft's shim, with Secure Boot turned on, read Broadcom KB 423893. It explains the options and what you may need to do inside the guests.
