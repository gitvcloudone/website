## What
Until now every EVS case went through AWS Support. If you have an active VCF subscription, you can now open VCF software cases directly with Broadcom. AWS Support still covers the whole stack, and Broadcom only covers the VCF software.

## Why it matters
For a VCF software problem, going straight to Broadcom can save a hop. Anything about EC2 hosts, VPC networking or the EVS API still goes to AWS.

## Who it's for
EVS customers with a Broadcom support entitlement.
