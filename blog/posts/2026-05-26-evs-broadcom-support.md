Until now every Amazon EVS case went through AWS Support. If you have an active VCF subscription, you can now open VCF software cases directly with Broadcom. AWS Support still covers the whole stack, and Broadcom covers only the VCF software.

For a pure VCF software problem, going straight to Broadcom can save a hop. Anything about EC2 hosts, VPC networking or the EVS API still goes to AWS, so it helps to agree internally on who opens which kind of case.
