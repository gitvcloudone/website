The standalone VMware Telco Cloud Platform (TCP) licensing SKUs reached end of availability on November 2, 2026. Telco customers are now fulfilled through the regular VCF license and SKU, and the platform is called VMware Cloud Foundation Telco (VCF Telco).

In practice this means TCP stops being a separate product line. Telco features, including those already shipping and the ones in development for the telco segment, come with the VCF SKU. Many operators already run VCF for their IT estate, so the practical effect is one platform and one operating model for virtual network functions (VNFs), cloud-native network functions (CNFs), IT workloads and AI, instead of separate network and IT clouds.

The capabilities listed for VCF Telco are mostly existing VCF features positioned for carrier requirements:
- **Fleet management:** one management domain for IT and telco workloads from data center to edge, with zero-touch lifecycle management.
- **Kubernetes support:** flexible 2-year long-term support with every minor Kubernetes release, so CNFs and VNFs can run on the same infrastructure.
- **Memory tiering and storage efficiency:** NVMe memory tiering that removes the hardware RAID dependency, plus compression with global deduplication, aimed at lowering server and storage cost.
- **Security and compliance:** customer-controlled encryption keys, in-jurisdiction operations and automated policy enforcement aligned to standards such as NIST and the UK Telecommunications Security Act. Zero-trust micro-segmentation is optionally available with VMware vDefend.

For existing Telco Cloud Platform customers, the announcement says no immediate action is needed on current deployments. If you renew or expand, check that your purchasing path now goes through the VCF SKU, and ask your account team how your current TCP entitlements map across.
